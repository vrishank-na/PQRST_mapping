## 1. Early stopping maybe stop too early ⭐⭐⭐⭐⭐

Me see:

* Epochs = 50
* Patience = 8

Now training many patients.

Before:

* one record
* converge fast

Now:

* many morphologies
* harder problem
* validation noisy

So patience 8 maybe stop before network learn universal ECG.

Me try

```
Epochs = 150
Patience = 20
```

or even

```
Patience = 25
```

### Evaluate

Plot

```
Train Loss
Validation Loss
```

If validation still going down when stop happen → early stopping too aggressive.

Keep if helps external QTDB.

# 6. Loss function ⭐⭐⭐☆☆

Notebook use

```
HuberLoss(delta=0.5)
```

Me actually like this.

Would NOT replace immediately.

But add small morphology preservation loss.

Instead of only

```
artifact prediction
```

also compute

```
Recovered ECG

=

Input - Prediction
```

Then

```
Loss

=

Huber(predicted_artifact)

+

0.2*MSE(recovered_clean)
```

Reason

Even though algebraically MSE same, Huber not exactly same.

Small clean reconstruction term may encourage morphology preservation.

Need experiment.

If no gain

remove.
