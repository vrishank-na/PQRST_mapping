# 13. EVENT-LEVEL TP / FP / FN

For P:

```text
TP_P
FP_P
FN_P
```

For T:

```text
TP_T
FP_T
FN_T
```

Definitions:

```text
TP = matched predicted/reference event
FP = predicted event with no reference match
FN = reference event with no prediction match
```

Then calculate:

```python
Sensitivity = TP / (TP + FN)

PPV = TP / (TP + FP)

F1 = 2 * PPV * Sensitivity / (PPV + Sensitivity)
```

Use safe zero-division handling.

These must be explicitly labelled:

> EVENT-LEVEL sensitivity / PPV / F1

Do NOT confuse them with the notebook's existing sample-level precision/recall/F1.
